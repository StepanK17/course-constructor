### Краткое техническое задание для Backend-сервиса «Конструктор курсов»

**Цель:** Создать центральный API для платформы, которая автоматически генерирует персонализированные учебные курсы на основе материалов пользователя или интернета с использованием RAG.

**Основной стек:** Go, PostgreSQL (основные данные), Redis (очереди задач и кэш), MinIO/S3 (хранение файлов), JWT для авторизации.

---

### 📁 Основные модули и что они делают:

1.  **Аутентификация (`/api/v1/auth/`)**
    *   Регистрация, вход, выход, обновление токена.
    *   Защита паролей с помощью bcrypt, токены живут 15 минут (`access`) и 7 дней (`refresh`).

2.  **Документы (`/api/v1/documents/`)**
    *   Загрузка файлов (PDF, DOCX, TXT, MD) в MinIO.
    *   У каждого пользователя свой лимит (например, 20 файлов, 100 МБ).
    *   После загрузки файл отправляется в очередь Redis на обработку AI-сервисом (например, для извлечения текста).

3.  **Курсы (`/api/v1/courses/`)**
    *   **Генерация:** Пользователь задает тему, цель, уровень — сервис создает задачу генерации и ставит её в очередь Redis для AI-сервиса.
    *   **Отслеживание статуса:** Можно проверить, на каком этапе (`pending`, `processing`, `completed`) находится создание курса.
    *   **Список и просмотр:** Получение списка своих курсов (с фильтрами и пагинацией) и деталей конкретного курса со структурой уроков.

4.  **Уроки и прогресс (`/api/v1/lessons/`, `/api/v1/progress/`)**
    *   Получение содержимого сгенерированного урока (текст, код, тесты).
    *   Отметка уроков как пройденных и автоматический расчёт общего прогресса по курсу.

---

### 🗃️ Как хранятся данные (PostgreSQL, основные таблицы):

*   `users`: Профили пользователей.
*   `documents`: Информация о загруженных файлах (имя, размер, статус обработки).
*   `courses`: Метаданные курсов (название, описание, уровень, параметры генерации).
*   `lessons`: Содержимое уроков, связанное с курсом.
*   `user_progress`: Отслеживание, какие уроки какой пользователь прошёл.
*   `generation_tasks`: Очередь и статус задач на создание курсов.

### 🔁 Как работает асинхронная генерация (Redis):
1.  Пользователь нажимает «Создать курс» во фронтенде.
2.  **Backend (Go)** создает запись в `generation_tasks` и кладет сообщение в очередь Redis (`generation_queue`).
3.  **Отдельный AI-сервис (Python/другой)** постоянно «слушает» эту очередь, забирает задачу, выполняет (общается с LLM, RAG) и обновляет статус задачи и данные курса в БД.
4.  **Пользователь во фронтенде** видит статус «В процессе», а по готовности — «Курс создан».

### ⚙️ Что нужно для запуска:
1.  **Переменные окружения** для настройки подключений (URL БД, Redis, ключи).
2.  **Docker-образ** для простого развертывания.
3.  **Миграции БД** для создания таблиц.

---

### 🎯 Итог: что получится?
**REST API**, который позволяет:
*   Пользователям зарегистрироваться и войти.
*   Загружать учебные материалы (документы).
*   Запускать создание персонализированного курса по запросу, выбирая тему, сложность и источники.
*   Отслеживать процесс генерации в реальном времени.
*   Изучать сгенерированные пошаговые уроки и следить за своим прогрессом.

**Главная фишка:** Вся тяжелая работа по генерации контента (общение с LLM, поиск в RAG) выполняется асинхронно в фоне, не блокируя пользователя. Backend лишь управляет задачами, статусами и предоставляет готовые данные.
